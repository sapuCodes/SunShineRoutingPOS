Free Issue Rules

Automatic free issues. When a bill has enough units of a product, the free product is added to the bill by itself. Use Slabs for “10 → 1 free, 20 → 3 free, 50 → 7 free”: only the highest slab reached is given.

Free items are limited by available stock. Rules apply to every bill. You can edit a rule any time — changes apply to the next bill. Turn a rule off to stop it without deleting it.

Business Profile

This appears on the header of every invoice, receipt, and report. Stored only in this browser.

🔒 Change Password

This is a local access lock for this browser only — not encryption. Anyone with access to this device and localStorage could bypass it, so don't rely on it for sensitive data.

💾 Backup & Restore

Download a full backup file of everything stored in this browser — business profile, inventory, sales, customers, routes, returns and credit receipts. Keep the file somewhere safe (email, cloud drive, USB). Restoring will overwrite whatever is currently in this browser.

Tip: download a fresh backup regularly, and especially before clearing data or switching devices/browsers. Your password is not included in the backup — you'll keep whatever password is already set on this browser.

📲 Phone App — works without Wi-Fi

Send the products file to the reps' phones (WhatsApp, USB, Bluetooth). When they return, import the sales file they send back — invoices, stock and credit update automatically. Cost prices are never put in the phone file.

Tip: import the phones' sales files first, then save a fresh products file, so stock levels on phones are correct.

📱 Mobile POS Sync

Connects this system to the Mobile POS server. Sync Now first brings the reps' mobile sales into this system (invoices, stock, credit), then sends the latest products, prices, outlets and outlet discounts to the phones. Cost prices are never sent to phones.

Danger Zone

Permanently erase all inventory, sales history, and profile data stored in this browser. This cannot be undone.

Or erase only the transaction data (sales, returns, credit receipts, GRN, targets) while keeping your customers, routes and business profile.

Distribution Sales & Billing System — fully offline, single-file build. All data is stored locally in this browser only.
